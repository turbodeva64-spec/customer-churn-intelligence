# Data Directory Structure & Governance (`data/`)

## Directory Layout
- `data/raw/`:
  - Source CSV (`Telco-Customer-Churn.csv`, `7,043` rows, `21` columns) and SQLite database (`telco_churn.db`).
  - **Git Policy**: Excluded from version control via `.gitignore` (`data/raw/*.db`, `data/raw/*.csv`) to prevent committing raw customer dumps or binary database artifacts.
- `data/processed/`:
  - `cleaned_churn.csv`: Validated, type-enforced dataset (`7,043` rows, `28` columns) generated by `python3 -m src.clean_data`.
  - `data_dictionary.csv`: Full schema documentation (`28` fields, data types, null counts, and business definitions).
  - `powerbi/`: 5 Star-Schema CSV tables (`Fact_Customer_Churn.csv`, `Dim_Customer_Profile.csv`, `Dim_Service_Subscription.csv`, `Dim_Billing_Contract.csv`, `Summary_Segment_KPIs.csv`) generated by `python3 -m src.export_powerbi`.
- `data/predictions/`:
  - `customer_risk_predictions.csv`: Full customer-level risk scoring (`7,043` rows) with `Churn_Probability`, `Predicted_Risk_Tier` (`High Risk`, `Medium Risk`, `Low Risk`), and `Expected_Monthly_Revenue_Loss`, generated by `python3 -m src.predict_customers`.

## Reproducibility
Run the complete data pipeline from the repository root:
```bash
python3 -m src.inspect_data
python3 -m src.clean_data
python3 -m src.evaluate_model
python3 -m src.predict_customers
python3 -m src.export_powerbi
```
